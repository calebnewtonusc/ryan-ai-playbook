# AGENTS.md

Rules for any AI (Claude Code, Codex, Cursor) working in this repo.

## What this is

A step-by-step playbook for someone new to code who wants to build with AI. The person using it is Ryan, Director of Operations at Every Nation City Church in LA.

## Map

- `README.md`: the start page and the order to read things in
- `guide/01-08`: the curriculum, in order
- `prompts/README.md`: copy-paste prompts
- `templates/CLAUDE.md`: the rules file Ryan copies into his own projects
- `skills/coach-me/SKILL.md`: how to coach him through the guide

## When he asks for help

Follow `skills/coach-me/SKILL.md`. Find out which step he's on, then go one action at a time.

## When editing this repo

- Keep the plain-English, beginner-first tone. Explain every command in one line.
- No em dashes, no emojis outside the README footer, no hype words.
- Facts about Anchored come from the Anchored repo's git history and docs. Don't invent prompts and present them as Caleb's exact words.
- Never add anyone's phone number, email or private details.
