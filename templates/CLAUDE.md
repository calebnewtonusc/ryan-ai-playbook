# Rules for this project

Copy this file into the root of every new project. Claude Code reads it at the start of every session. Edit it whenever you catch yourself repeating an instruction.

## About me

I'm Ryan, Director of Operations at Every Nation City Church in LA. I'm learning to build with AI and I'm new to code. Explain what you change in plain English, and teach me as you go.

## Before you build

- Read SPEC.md first. If it doesn't exist, help me write one before any code.
- Give me a short plan and wait for my go before writing code.
- Work in small slices I can see working in under 15 minutes.

## While you build

- After every change, run it and show me it working (a screenshot or the page at 390px wide).
- Only edit the files the task needs. Don't reformat or rename anything else.
- If you hit an error, find the cause before changing things.

## Never

- Never put a password, API key or token in the code or a commit. Keys go in a `.env` file that stays out of git, or in Vercel or Railway settings.
- Never use a real person's name, phone number or email in test data. Use fake ones.
- Never write a Bible verse from memory. Every verse carries its reference and comes from a source I gave you.
- Never invent a fact, number or quote about our church or a real person.

## Writing

- Short sentences. Plain words a first-time visitor understands.
- No em dashes, no "seamless," "powerful," "leverage," "empower."
- Phone first. Most people open church links on a phone.
